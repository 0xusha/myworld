# My World — Typography Globe 🌍❤️

A creative coding project that renders a typography-based globe in the shape of an organic, hand-drawn heart. The ocean, continents, and borders are dynamically formed by densely packing translations of "My World" in over 30 different languages.

## ✨ Features
* **Dynamic Text Packing:** Uses a custom justification algorithm to densely pack words inside the heart boundary without overlapping.
* **Organic Shape Mapping:** The text perfectly traces an asymmetrical, hand-drawn doodle heart and custom continent shapes.
* **Animated Reveal:** Words gracefully fade and slide into existence one by one, settling into their respective ocean (blue), continent (green), or border (white) colors.
* **Zero Dependencies:** Built entirely with vanilla JavaScript and the HTML5 Canvas API.

## 🚀 How to Run
No server or build tools required! 
1. Clone this repository or download the source code.
2. Open the `index.html` file in any modern web browser.
3. Watch the typography globe build itself.

## 🛠️ Built With
